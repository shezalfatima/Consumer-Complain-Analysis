# Consumer Complaint Analysis using Excel

This project is a simple and interactive analysis of consumer complaints data collected by the Consumer Financial Protection Bureau (CFPB). 
The goal is to identify trends in financial product issues, highlight which companies receive the most complaints, and understand how those complaints are handled.

All analysis was done using Microsoft Excel with the help of pivot tables, slicers, and visual dashboards.


# About the Dataset

- **Source:** [Consumer Complaint Database – data.gov](https://catalog.data.gov/dataset/consumer-complaint-database)
- The dataset includes real complaints submitted by consumers about financial services like credit cards, loans, and checking accounts.
- It contains information like:
  - Type of product or service
  - Issue reported
  - Company name
  - Submission method (web, phone, etc.)
  - Company response and resolution status
  - Consumer’s location (by state)


## Tools & Techniques Used

- **Microsoft Excel**  
- **Pivot Tables** for organizing and summarizing data  
- **Slicers** for interactive filtering  
- **Charts** (bar, pie, line, stacked bar) to visualize trends  
- **Functions:** COUNT, IF, Conditional Formatting, Sorting, Filtering


## Dashboard Features

The dashboard helps users:
- See which products and companies receive the most complaints
- Compare complaint resolutions
- Analyze trends by year, state, or submission channel
- View responses (e.g., timely, untimely, with/without relief)


## Key Findings

- **Credit reporting** is the most complained-about category.
- Some major companies appear more frequently than others.
- **Most complaints are submitted online.**
- Many companies respond on time, but some still don’t offer any resolution.
- Complaint trends can vary by product type and region.
